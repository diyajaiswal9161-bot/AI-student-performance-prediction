# AI-Driven Student Performance Prediction System

## 📌 Project Overview
The AI-Driven Student Performance Prediction System is a Machine Learning based web application that predicts student performance using academic and personal factors.

This project was developed during the IBM PBEL Internship under the guidance of Shweta Ma'am.

## 🎯 Objective
The main objective of this project is to analyze student data and predict performance. It helps identify students who may need additional support and improvement strategies.

## 🛠️ Technologies Used

- Python
- Machine Learning
- Flask (Backend Framework)
- HTML
- CSS
- Scikit-learn
- Pandas
- NumPy

## 🤖 Machine Learning Model

A trained Machine Learning model is used to analyze student information and generate performance predictions.

## 🌐 Web Application

The web application provides an easy interface where users can enter student details and get prediction results instantly.
